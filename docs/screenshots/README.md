# 界面截图目录

把发布用的界面截图放在这里，并在 [README](../../README.md) 的「界面截图」章节中引用，
例如：

- `docs/screenshots/main-dark.png` — 主界面（暗黑 + 液态玻璃）
- `docs/screenshots/main-light.png` — 主界面（明亮）
- `docs/screenshots/start.png` — PCL 风格启动页（含皮肤管理）
- `docs/screenshots/isolation.png` — 版本隔离
- `docs/screenshots/theme.png` — 主题 / 配色 / 启动图设置
- `docs/screenshots/instances.png` — 实例管理
- `docs/screenshots/settings-jvm.png` — JVM 参数编辑器
- `docs/screenshots/toolbox-mods.png` — 百宝箱 · Mod 管理
- `docs/screenshots/toolbox-diagnose.png` — 百宝箱 · 崩溃诊断
- `docs/screenshots/toolbox-servers.png` — 百宝箱 · 服务器监控
- `docs/screenshots/optimize.png` — 百宝箱 · 一键优化

注意：

1. 截图前请先切换到一个**示例游戏目录**，避免暴露个人目录结构。
2. 不要把包含本机路径、账号名或 API Key 的截图提交到仓库。
3. 图片建议宽 1280–1600 px、体积小于 500 KB，优先使用 PNG。
